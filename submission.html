Deeper Understanding

What I did beyond the labs

Instead of using a basic cylinder mesh like in the labs I used Bezier curves and the Screw modifier to build the models. I followed YouTube tutorials to learn this and also made the lids as separate objects so they can animate on their own.

Audio using the browser's built in Web Audio API, different from the labs.

The official labels were not available online so I used ChatGPT to generate them by uploading the can photos and asking it to create flat label I could wrap around the models.

For the wireframe I did not just set wireframe to true on the existing materials because physically based materials look broken in wireframe mode. I swap them out for MeshBasicMaterial which ignores lighting completely so the lines always show up clean.

I added a loading overlay with a percentage so the user can see the model is loading instead of just seeing a blank canvas.

If the model fails to load a fallback shows the model image instead so the page never looks broken.

Load token system so switching products quickly never causes the wrong model to show up.

15 second timeout so the canvas never gets stuck loading forever.

The other models prefetch in the background after the first one loads so switching feels instant.

WebGL context loss recovery for when mobile browsers reclaim GPU memory.

Animation clock pauses when you switch browser tabs to save battery.

Full memory disposal every time you switch product so the browser does not slow down.

Animations play in reverse to close using timeScale negative one so I only needed one animation in Blender instead of two.

Soft shadow under the model made using the HTML Canvas API instead of Three.js shadow mapping.

ACESFilmic tone mapping for a cinematic colour on the lighting.

Gentle floating animation using a sine wave on the Y axis when the model is idle.

3 lightings Default, Studio and Sunset.

Visual testing : fonts, colours, spacing and alignment is very visually appealing across all pages.

Accessibility testing : alt text, colour contrast and aria-live status label perfect.
